# results/

Generated by `make` targets; not committed. Each file is listed with the command that writes it.

| File | Command |
|---|---|
| `inspect_utd.json` | `python -m edasynth inspect` |
| `alignment.csv` | `python -m edasynth align` |
| `realdata.json` | `python -m edasynth realdata --stored --raw` |
| `bank_utd.json`, `bank_utd.npz` | `python -m edasynth estimate --source utd` |
| `validation_utd.json` | `python -m edasynth validate --source utd --pytest` |
| `detectors_by_class.csv` | `python -m edasynth detectors --source utd` |
| `pilot_utd.csv`, `pilot_utd_R.json` | `python -m edasynth pilot --source utd` |
| `grid_metrics_utd.csv` (+ `variants_*`, `grid_labelnoise_*`) | `python -m edasynth grid ...` |
| `grid_summary_utd.csv`, `compatibility_utd.csv`, `sensitivity_utd.csv` | `python -m edasynth analyze --source utd` |
| `protocol_planning_utd.csv` | `python -m edasynth power --source utd` |

`results/smoke/` holds the development run on AWW. **Its numbers are not results.**
