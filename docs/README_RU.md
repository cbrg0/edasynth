# Краткое руководство на русском

Это руководство для читателя, которому удобнее по-русски. Основная документация
репозитория написана на английском (README.md, docs/METHOD.md), и при расхождении
действует английский текст.

## О чём проект

Электродермальная активность (ЭДА) — это проводимость кожи, которую меняют потовые
железы под управлением симпатической нервной системы. На запястье электрод сдвигается
при движении руки, и в записи появляются пики, провалы и ступеньки, которые к
физиологии отношения не имеют. Это артефакты движения. Вопрос проекта: помогает ли
акселерометр того же браслета находить такие артефакты лучше, чем модель, которая
видит только ЭДА.

Синтетические данные сами по себе на этот вопрос ответить не могут. Ответ зависит от
того, как часто движение запястья на самом деле нарушает контакт электрода, а эту
величину ни один доступный набор данных не измерял. Поэтому мы строим условную карту:
задаём связь между движением и артефактами в разных вариантах и для каждого варианта
считаем выигрыш от акселерометра с доверительным интервалом. Каждый результат на карте
звучит так: «если связь такая, то выигрыш такой».

## Как устроены данные

Ускорение берётся настоящее: 20 человек из набора PhysioNet `noneeg` (Birjandtalab et
al., 2016), частота 8 Гц. ЭДА строится программой. Параметры для неё (шум, шаг
квантования, частота и размер реакций, форма тонического уровня, форма артефактов)
измеряются на настоящих записях тех же людей. Движение для синтетического участника
берётся от одного человека, а физиология от другого, чтобы модель не могла узнать
человека по совпадению двух сигналов.

Пять классов артефактов: пик давления (C1), провал при потере контакта (C2),
ступенька уровня (C3), колебания при ходьбе (C4, положительный контроль),
выпадение или насыщение сигнала (C5). Разметка «артефакт / чисто» известна точно,
потому что артефакты добавили мы сами.

## Что уже сделано и что нет

Полная таблица статусов: [STATUS.md](STATUS.md). Коротко:

* Код всех шагов написан, модульные тесты проходят.
* Повторён реальный базовый результат по опубликованным признакам UTD: AUPRC 0.4486
  без ускорения и 0.4754 с ним, разница +0.027, 95 % доверительный интервал от
  −0.002 до +0.058. Интервал включает ноль, то есть данные не показывают ни выигрыша,
  ни его отсутствия.
* Весь конвейер прогнан от начала до конца на учебных данных AWW (один человек).
  Это проверка того, что код работает, а не научный результат. На AWW все проверки
  G2–G6 не пройдены; причины и вопросы, которые нужно решить до основного прогона,
  перечислены в STATUS.md.
* Шаги, которым нужны сырые сигналы UTD (сопоставление разметки, оценка параметров,
  проверки G2–G7, основная сетка), здесь не запускались: среда, в которой собирался
  репозиторий, не имела доступа к PhysioNet. Их нужно запустить на своём компьютере.

## Что запустить на своём компьютере

```bash
git clone https://github.com/cbrg0/edasynth.git
cd edasynth
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,reference]"
make before-tag   # данные, тесты, проверка единиц и стадий, сопоставление разметки,
                  # оценка параметров, проверки G1-G7, пилот
```

Дальше нужно разобрать открытые вопросы в конце [STATUS.md](STATUS.md), затем
поставить тег и отправить его на GitHub:

```bash
git tag prereg-synth-v1 && git push --tags
make after-tag    # сетка, варианты, анализ, мощность, рисунки
```

Порядок важен: тег с датой доказывает, что правила решения были зафиксированы до
получения результатов.

## Чего этот репозиторий не утверждает

* Что акселерометр помогает людям. Синтетика показывает только условные ответы.
* Что неподвижная рука в будущем лабораторном протоколе даёт идеальную разметку.
  Это опорный сигнал, у которого есть свои ошибки.
* Что отсутствие выигрыша на UTD доказывает его отсутствие в природе. Интервал
  включает ноль, и данных для такого вывода мало.
