# Figures

Drawn by `python -m edasynth figures --source utd` from the files in `results/`.

| File | Shows |
|---|---|
| `F0-summary.png` | the main result: gain from acceleration against *c* |
| `F1-real-vs-synthetic.png` | a real recording next to a synthetic participant built from the same physiology |
| `F2-artifact-classes.png` | each artifact class added to the same clean segment |
| `F3-realism.png` | how each EDA feature differs between real and synthetic clean windows (check G3) |
| `F4-map-C1-C2-C3-C5.png` | the full map for the mixture: mean gain over *c* and κ for every δ<sub>max</sub> and π<sub>r</sub>; * = useful |
| `F5-by-class.png` | gain against *c* for each artifact class |
| `F6-cost.png` | share of genuine movement-evoked responses flagged as artifacts |

PDF versions and the maps of single classes are written by the same command.
